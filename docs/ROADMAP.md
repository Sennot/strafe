# Roadmap — фазы и приёмка

Нумерация фаз используется в VERIFY-метках по всему коду. Каждая фаза
заканчивается чеклистом приёмки — не переходи дальше, пока он не закрыт.

## P0 — Каркас (этот коммит) ✅
Структура модулей, SessionState, BestRunPolicy, LabelFreezer, CheckpointBank,
PracticeUICleaner, RestartController, хуки, MH-interop, CI.

## P0.5 — Первая компиляция (первое действие следующего контрибьютора)
Сборка через GitHub Actions; чинятся только сигнатуры/поля, помеченные
VERIFY. Никакой новой логики.

- [ ] Actions зелёный, артефакт `.geode` собирается
- [ ] Мод грузится в игре, в логе баннер `[GhostPractice] loaded`
- [ ] В логе строка про MegaHack (detected / not loaded)
- [ ] Если сигнатуры из ARCHITECTURE §hook-verify не сошлись — поправить
      в `BindingsCompat`/хуках, снять VERIFY-метки

## P4 — Расширенный снапшот

- [ ] Каунтеры/группы, не восстанавливаемые ванилью
- [ ] Камера (позиция/зум/тряска)
- [ ] Позиция музыки (fmod channel position) — синхронизация после респауна
- [ ] Скорости групп X

## P5 — Партиклы (по желанию, дорого)
- [ ] Снапшот `CCParticleSystemQuad`-массивов (позиции/жизни частиц)
- [ ] Настройка-выключатель (дорого на тяжёлых уровнях)

## Правила приёмки
1. Каждая фаза проверяется в реальной игре, не «на глаз по коду».
2. Ничего не писать в сейв (Volatile-Only) — проверяется тем, что после
   выхода из уровня обычный прогресс/статистика не изменились.
3. Логи `[GhostPractice]` — единственный способ отладки; не удалять их.
