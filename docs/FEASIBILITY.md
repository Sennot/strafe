# Feasibility — что возможно, что нет, и откуда это известно

Оценка от 2026-10-07. Цель: GD 2.2081, Geode 5.10, MegaHack v9.1.3 (кряк
PatchTeam; для наших выводов важно только то, что кряк не меняет механизм
рендера UI — импорты/RTTI это подтверждают).

## Сводка

| # | Фича (формулировка пользователя) | Вердикт | Сложность |
|---|---|---|---|

## Доказательная база по MegaHack (статический анализ пакета)

Проведён анализ структуры пакета `absolllute.megahack.geode` v9.1.3
(заголовки PE, таблица импортов, RTTI-строки, строковые данные, таблица
экспортов). Дизассемблирование кода не выполнялось и не требовалось.

### F1. Лейблы MH рендерятся cocos-нодами игры

- Импорты DLL: `libcocos2d.dll`, `libExtensions.dll`, `Geode.dll`,
  `fmod.dll`, `glew32.dll`, `OPENGL32.dll` — и **никаких** d3d11/dxgi.
  Собственного оверлея нет → UI MH — ноды в дереве сцены игры.
- RTTI в бинарнике: `.?AVCCLabelBMFont@cocos2d@@`,
  `.?AVCCLabelProtocol@cocos2d@@` + собственные обёртки
  `.?AVLabel@text@tabcore@@`, `.?AVLabel@status@@`.
- Строки форматов: `' FPS'`, `' CPS'`, `'%*sCPS: %.*s'`,
  `'Best Run: {}'`, `'Attempt {}'`.
- Geode-ноды: `checkpoints-label`, `percentage-label`, `ep-label`,
  `os-label` (зависимость `geode.node-ids >= v1.22.0` подтверждает
  использование Geode node-ID).

Следствие: заморозка реализуется перезаписью текста каждый кадр
(`LabelFreezer`) — без хуков на MH, без оффсетов, переживает его
обновления.

### F2. У MH есть экспортный API

Экспорт `hackpro::extensions`: `isHackEnabled`, `setHackEnabled`,
`getConfigVar<T>`/`setConfigVar<T>` (bool/double/int64/string/vector),
`registerListener<T>`, `registerHackListener`, `showMessage`,
`registerTab`, и `mega::utils::safe_mode::`
{`areCheatsEnabled`,`hasCheatedInAttempt`,`disableAllCheats`}.

Используется опционально (`src/mh/MegahackInterop.cpp`), всё деградирует
в no-op, если MH отсутствует или экспорт переименован. Это его
собственный публичный интерфейс — ни реверса, ни патчинга.

### F3. Сборка не упакована классическим протектором

Секции PE штатные (`.text .rdata .data .pdata .tls .rsrc .reloc`), без
секций VMProtect/Themida. Но код обфусцирован компиляторными средствами,
и глубоко лежащие оффсеты меняются между версиями — ещё одна причина
строить на строках/нодах/экспортах, а не на адресах.

## Детальные вердикты

### 1. Скрытие practice UI — ✅
Кнопки — ноды UILayer (прячем по эвристике «меню в нижнем левом углу»,
уточняется по дампу дерева). Алмазы чекпоинтов — **дифф нод** вокруг
`createCheckpoint` (версие-независимо). Заголовок паузы «Practice Mode» —
замена текста. Всё восстановимо при выходе из practice.

### 2. Экран победы — ✅
`LevelCompleteLayer::init(GJGameLevel*, bool, bool)` — принудительно
`(false, false)` при активной сессии. Какой именно bool флаг practice —
проверяется одним прогоном (лог печатает входящие значения). Меняется
только презентация; статистика/награды идут по practice-пути движка.

### 3. Заморозка лейблов — ✅ (механизм доказан, см. F1)
Пиннинг текстов каждый кадр после апдейтов MH. FPS-лейбл MH обновляется
раз в секунду сам — этого достаточно; главное, что «застывшие» значения
не выдают чекпоинты (не растут Clicks/Checkpoint-каунтеры, Time не
копится). Риск: новый лейбл вне паттернов → решается настройкой
(префиксы/ID), «Debug: dump node trees» показывает всё живьём.

### 4. Best Run — ✅ (реализовано в SessionState/BestRunPolicy)
0→25, чекпоинт на 25 → Best Run 25. 25→50 без смерти, чекпоинт → 50.
Смерть на 40 без чекпоинта → откат к 25. Растёт в реальном времени от
банка. Удаление чекпоинта откатывает банк к предыдущему (через
CheckpointBank).

### 5. Стартпозы — ⚠️ ждём решения пользователя
Два кандидата: (a) абсолютные проценты; (b) «заработанные» = абсолют −
baseline. Реализовано как (a) через `StartposPolicy`; смена — одна
строка. Не выбирать за пользователя.

### 6. Абсолютная заморозка мира — ⚠️ честная оценка
Ванильный practice-чекпоинт 2.2 уже восстанавливает больше, чем в 2.1
(физика, часть каунтеров). Наши ступени P3–P5 добавляют остальное
(см. ARCHITECTURE §6). 100% идентичность (RNG-стейт, аудио- DSP,
попиксельные партиклы) недостижима на практике; визуальная
неотличимость в записи — реалистичная цель. Каждая ступень включается
только парой capture+restore, без мёртвых полей.

### 7. Финальный рестарт — ✅ (F9)
Вайп банка+чекпоинтов, `resetLevel` с 0, лейблы оживают, Attempt 1.
Кнопка в UI — тривиально добавить поверх `performFinalRestart`
(контракт не изменится). Хоткей временно через GetAsyncKeyState,
миграция на Geode keybinds API — ROADMAP P2.

### 8. Прогрессбары/проценты — ✅
Зелёный маркер best: in-memory перезапись `m_normalPercent` каждый кадр.
Текущий процент и так показывается движком. «New Best»-попап и маркеры
смерти — ROADMAP P2 с той же in-memory схемой.

### 9. Настоящая запись в статистику — ❌ осознанно нет
Volatile-Only (ARCHITECTURE §7): сейв не трогаем — риск порчи и банов.
Это граница мода, не техническое ограничение.

## Риски

- **Обновления GD/Geode/MH**: строки, node-ID и экспорты стабильнее
  оффсетов, но не вечны. Всё внешнее — в настройках/конфигах.
- **Крякнутая сборка MH**: может отличаться от оригинала поведением
  лицензирования; на механизмы из F1–F2 не влияет.
- **Бан-риски при публикации фейк-ранов**: списки/лидерборды сообщества
  это отслеживают; мод не предназначен для подачи фейков на демон-листы.
