# Ghost Practice

Исследовательский мод для **Geometry Dash 2.2081** на **Geode 5.10**:
practice-сессия, которая снаружи выглядит как обычный normal-прогон.

> Research mod for GD 2.2081 (Geode): practice sessions presented as
> normal-mode runs. Presentation-only, in-memory only.

## Возможности (P0-каркас)

- **Скрытие practice-UI** — кнопки чекпоинтов, алмазы, надписи «Practice Mode»
- **Экран победы** в варианте normal-режима
- **Заморозка лейблов** MegaHack V9 (FPS/CPS/Best Run/Clicks/Time/...) в
  момент первого чекпоинта — через cocos-дерево, без реверса и патчей
- **Best Run по банковой семантике**: чекпоинт «банкует» процент, смерть
  между чекпоинтами откатывает к банку, значение живое в реальном времени
- **Финальный рестарт (F9)** — вайп чекпоинтов и рестарт с 0%
- **Прогресс-бар** — зелёный маркер best имитирует normal-ран (in-memory)

Все настройки — в меню мода внутри игры.

## Сборка (только GitHub Actions)

1. Запушь репозиторий на GitHub.
2. Workflow `.github/workflows/build.yml` (geode-sdk/build-actions) собирает
   мод автоматически на каждый push; артефакт `.geode` — во вкладке Actions.
3. Положи артефакт в `Geometry Dash/mods/` вместе с Megahack.

Локальная сборка не требуется (по решению владельца). Если очень надо:
установи [Geode SDK](https://geode-sdk.org) → `cmake -B build && cmake --build build`.

## Границы (осознанные)

- **Volatile-Only**: сейв-файл и аккаунт-статистика не трогаются никогда
  (риск порчи сейва и банов). Вся фальшь живёт только в текущей сессии.
- Статический реверс Megahack не выполняется и не нужен: его лейблы —
  cocos-ноды (доказано, см. FEASIBILITY), а его собственный экспортный API
  `hackpro::extensions` используется опционально через GetProcAddress.
- «Абсолютно точная» заморозка мира (партиклы и пр.) — поэтапная
  (P3–P5 в ROADMAP); 100% побитовая идентичность недостижима, и это
  задокументировано честно.
- Файл `absolllute.megahack.geode` — крякнутая сборка; **не коммить его в
  репозиторий** (.gitignore уже исключает `*.geode`) и не распространяй.

## Дисклеймер

Мод создан в исследовательских целях. Выдавать фейковые прогоны за
легитимные (демон-листы, конкурсы, «доказательства» скилла) — обман
сообщества; авторы мода таких использования не поддерживают.
